# Contributing to Unfiltered Organism

Thank you for your interest in contributing to **Unfiltered Organism**! Because this project is currently in its MVP phase, collaboration is handled directly.

## How to Reach Out
If you have questions, feedback, bug reports, or suggestions for improving the orchestrator loop, sandbox safety rails, or RAG memory vault, please reach out directly via email:

* **Email:** [adrianestonactoc@gmail.com](mailto:adrianestonactoc@gmail.com)

## Contribution Guidelines
As the project grows, formal contribution guidelines (such as pull request workflows and coding standards) will be established. For now, feel free to fork the repository, experiment locally, and reach out via email to discuss ideas or share your own implementations!
